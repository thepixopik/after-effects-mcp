# Pixopik Motion Studio — After Effects Video & Screen Studio MCP

AI-powered **Screen Recording Video Editor + SaaS Explainer Studio** for Adobe After Effects.

## Features
- **Advanced 2-Stream Screen Recorder:** Captures clean cursor-free `60 FPS` `.mp4` screen video + `60 Hz` `motion.json` cursor & click telemetry.
- **1-Click Screen Studio Rig in After Effects:** Generates razor-sharp AE Vector Cursor, smooth Bezier click-zooms, click ripples, rounded SaaS window frame, and studio gradient backdrop.
- **YouTube `16:9` & Shorts `9:16` Modes:** Auto-reframes horizontal screen recordings into vertical Shorts with smart cursor-tracking camera motion.
- **16 Live Gemini MCP Tools:** Control zooms, spotlights, privacy blurs, SaaS callouts, kinetic titles, 3D tilts, frame previews, and Render Queue live.

## 1-Click Windows Install
1. Download ZIP and extract anywhere.
2. Double-click **`INSTALL_AE_PLUGIN.bat`**.
3. Open **Adobe After Effects** -> **`Window > Extensions > Pixopik Motion Studio`**.
4. Connect Gemini to: `https://after-effects-mcp.goutamboronew.workers.dev/mcp`
